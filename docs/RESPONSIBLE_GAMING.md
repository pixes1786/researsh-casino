# Responsible Gaming Policy

**This project is a research prototype. No real money is involved.**

## Scope

Research Casino Platform exists to study:
- UX of gambling-style interfaces
- Retention mechanics
- Security and anomaly detection

Every balance is virtual currency (RC). No deposits, withdrawals, purchases, or
exchange to real money are possible anywhere in the system.

## Player protections (UX-level, no real-money implications)

- Session time reminders (planned)
- Self-exclusion toggle (data model ready)
- Virtual spending limits (planned)
- Cool-off period (planned)
- Reality checks (planned)
- Links to real-world help resources

## Help resources

If you or someone you know struggles with gambling, reach out locally:

- Russia: 8-800-2000-122 (child helpline), specialized centers
- EU: https://www.begambleaware.org/
- USA: 1-800-522-4700 (National Problem Gambling Helpline)
- International: https://www.gamblingtherapy.org/

## Operator commitments

- We never accept real money in this prototype.
- We never integrate with real payment providers.
- We never run real KYC/AML.
- We never pay affiliates.
- We publish a security contact for responsible disclosure.
